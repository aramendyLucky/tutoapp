Bienvenido al MacBook Pro M5

Lo primero que hacer al encenderlo por primera vez

🏎 Qué hay de nuevo en M5

CPU hasta 4x más rápida que Intel. 307 GB/s de ancho de banda de memoria. Neural Engine de 38 billones de ops/s.

⚙️ Setup inicial recomendado

Activar FileVault, desactivar iCloud Drive para proyectos, habilitar Firewall, configurar hot corners.

⚡
Verificá que estás en Apple Silicon: abrí Terminal → uname -m → debe decir arm64.

⚙️ Configuración Inicial del Sistema

System Settings · dónde encontrar 
# Estas configuraciones están en System Settings (⚙️)

── General ──────────────────────────────────────────────────
Software Update → Automáticas ON (pero "Install App Updates" manual)
AirDrop & Handoff → ON (conectividad con iPhone/iPad)

── Privacy & Security ───────────────────────────────────────
FileVault → Turn On...     # cifrado completo del disco
Firewall  → ON             # bloquear conexiones no autorizadas
Full Disk Access → dar permiso a Terminal.app

── Trackpad ─────────────────────────────────────────────────
Tracking Speed → Fast (7-8/10)
Tap to Click → ON          # clickear sin presionar
Three finger drag → ON     # Accessibility → Motor → Trackpad

── Keyboard ─────────────────────────────────────────────────
Key Repeat Rate → Fast     # teclas más responsivas
Delay Until Repeat → Short

── Mission Control ──────────────────────────────────────────
Hot Corners → BL: Desktop, BR: Mission Control, TR: Screensaver

── Dock ─────────────────────────────────────────────────────
Size → Pequeño
Magnification → Medium
Minimize using → Scale Effect  # más rápido que Genie
Show recent apps in Dock → OFF

🚀 Optimización para Desarrolladores

Aprovechá al máximo tu M5 con estas optimizaciones clave para el desarrollo.

💻 Homebrew (Gestor de Paquetes)

Instalar herramientas esenciales: `brew install wget git node yarn python3 ...`

📦 Gestión de Entornos Virtuales

Usa `venv` para Python o `nvm` para Node.js. Aislamiento de dependencias.

🗄️ Configuración de Dock

Mantén tu Dock limpio. Agregá apps de desarrollo y el Monitor de Actividad.

💡 Gestos del Trackpad Personalizados

Configurá gestos para Mission Control, App Exposé y Launchpad para mayor fluidez.

ℹ️
Para una experiencia de desarrollo óptima, considera instalar XCode desde la App Store. Incluye las herramientas de línea de comandos de Apple.

Personalización y Eficiencia

System Settings

Dock & Menu Bar: Ajusta el tamaño y la magnificación del Dock para un acceso rápido a tus aplicaciones. La 'Magnificación' puede ser útil para identificar iconos pequeños.

System Settings

Desktop & Dock: Configura 'Hot Corners' (Esquinas de acceso rápido) para activar Mission Control, mostrar el escritorio, o iniciar el salvapantallas con el ratón, mejorando la navegación.

System Settings

Accessibility → Pointer Control → Trackpad Options: Habilita 'Arrastrar con tres dedos' para una manipulación de elementos más fluida y ergonómica.

System Settings

Keyboard → Keyboard Shortcuts: Revisa y personaliza los atajos de teclado para acelerar tus flujos de trabajo. Considera asignar atajos para aplicaciones o funciones usadas frecuentemente.

Trucos de Mission Control para Developers

Navegar entre Spaces con Teclado

Usa Ctrl + ← / → para moverte entre tus espacios de trabajo (Spaces) de forma fluida sin interrumpir tu flujo.

Arrastrar Ventanas entre Spaces

Entra en Mission Control (Ctrl + ↑), haz clic y arrastra cualquier ventana de un Space a otro en la vista superior.

📁 Navegación y Archivos

bash · navigation 
# Navegación rápida
cd -              # volver al directorio anterior
cd ~              # ir a home
ls -la            # listar con ocultos y permisos
eza --icons -la   # ls moderno (si tenés eza instalado)
tree -L 2         # árbol de directorios 2 niveles

# Buscar archivos (rápido)
fd nombre.py      # buscar por nombre (más rápido que find)
rg "texto"        # buscar contenido en archivos (ripgrep)
fzf               # fuzzy finder interactivo

# Operaciones de archivos
cp -r origen/ destino/    # copiar carpeta completa
mv archivo.txt nuevo.txt  # mover/renombrar
rm -rf carpeta/           # eliminar carpeta (cuidado!)
pbcopy < archivo.txt      # copiar contenido al portapapeles
pbpaste > archivo.txt     # pegar portapapeles a archivo
open .                    # abrir carpeta actual en Finder
open -a "VS Code" .       # abrir con app específica

⚙️ Sistema y Procesos

bash · system 
# Información del sistema
uname -m              # → arm64 (Apple Silicon)
sw_vers               # versión de macOS
system_profiler SPHardwareDataType  # info detallada de hardware
sysctl -n machdep.cpu.brand_string  # modelo del CPU

# Procesos y rendimiento
top                   # monitor de procesos (q para salir)
htop                  # versión visual mejorada de top
ps aux | grep node   # buscar proceso específico
kill -9 PID           # forzar cierre por PID
pkill -f "nombre"     # cerrar proceso por nombre
lsof -i :3000         # ver qué usa el puerto 3000
kill $(lsof -t -i:3000)  # liberar puerto 3000

# Disco y memoria
df -h                 # espacio en disco
du -sh */             # tamaño de cada carpeta
du -sh * | sort -h   # ordenado por tamaño

bash · macos only 
# Portapapeles

Usuarios, Permisos y Acceso

Incluyendo la solución al Permission denied entre usuarios

bash · users & permissions 
━━━ INFORMACIÓN DE USUARIOS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
whoami                  # usuario actual
id                      # UID, GID y grupos del usuario
who                     # usuarios conectados ahora
dscl . list /Users     # todos los usuarios del sistema
dscl . read /Users/nombre # info de un usuario específico

━━━ CHMOD — PERMISOS DE ARCHIVOS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Formato: chmod [who][op][permissions] archivo
# who: u=user, g=group, o=others, a=all
# permissions: r=4(read), w=2(write), x=1(execute)
chmod 755 script.sh      # rwxr-xr-x (ejecutable para todos)
chmod 644 archivo.txt   # rw-r--r-- (lectura pública)
chmod 600 .env          # rw------- (solo el dueño)
chmod +x script.sh      # agregar permisos de ejecución
chmod -R 755 carpeta/   # aplicar recursivamente

━━━ CHOWN — CAMBIAR PROPIETARIO ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
chown usuario archivo.txt
chown usuario:grupo archivo.txt
sudo chown -R $(whoami) /carpeta/  # tomar propiedad recursiva

━━━ ACL — LISTAS DE CONTROL DE ACCESO ━━━━━━━━━━━━━━━━━━━━━━━━━
ls -le archivo.txt       # ver permisos ACL extendidos
chmod +a "usuario allow read" archivo.txt
🚨
Problema: Permission denied al acceder a archivos de otro usuario
bash · fix permission denied 
━━━ SOLUCIÓN 1: Copiar archivos del otro usuario (recomendado) ━━
sudo cp -r /Users/otro-usuario/proyecto/ ~/mi-proyecto/
sudo chown -R $(whoami) ~/mi-proyecto/
# Ahora tenés los archivos con tus propios permisos

━━━ SOLUCIÓN 2: Full Disk Access para Terminal ━━━━━━━━━━━━━━━━━
# System Settings → Privacy & Security → Full Disk Access
# Agregar Terminal.app (y/o iTerm2)
# Esto permite a Terminal leer archivos de otros usuarios

━━━ SOLUCIÓN 3: Compartir carpeta específica entre usuarios ━━━━
# En el otro usuario: crear carpeta en /Users/Shared/
mkdir -p /Users/Shared/proyecto-compartido
cp -r ~/proyecto/ /Users/Shared/proyecto-compartido/
chmod -R 755 /Users/Shared/proyecto-compartido/

━━━ SOLUCIÓN 4: Agregar tu usuario al grupo del otro ━━━━━━━━━━━
sudo dseditgroup -o edit -a tu-usuario -t user grupo-del-otro

━━━ DIAGNÓSTICO: Ver por qué está denegado ━━━━━━━━━━━━━━━━━━━━
ls -la /Users/otro-usuario/     # ver permisos del home
ls -le /Users/otro-usuario/proyecto/ # ver ACLs extendidos

Seguridad: SIP, SSH, Firewall

Configuración de seguridad esencial para developers

bash · security 
━━━ SIP (System Integrity Protection) ━━━━━━━━━━━━━━━━━━━━━━━━━
csrutil status    # → "enabled" es lo correcto y seguro
# NO deshabilitar SIP salvo que sepas exactamente qué hacés

━━━ SSH ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Generar clave SSH (ed25519 es el estándar moderno)
ssh-keygen -t ed25519 -C "tu@email.com"
cat ~/.ssh/id_ed25519.pub   # mostrar clave pública

# Agregar al agente SSH (se reinicia solo con macOS Keychain)
eval "$(ssh-agent -s)"
ssh-add --apple-use-keychain ~/.ssh/id_ed25519

# Configuración de múltiples hosts SSH
# Crear ~/.ssh/config:
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519

Host mi-servidor
  HostName 192.168.1.100
  User deploy
  IdentityFile ~/.ssh/deploy_key
  Port 2222

━━━ FIREWALL ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --getglobalstate
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --setglobalstate on

━━━ GATEKEEPER ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
spctl --status   # → assessments enabled
# Para abrir app no firmada (una sola vez):
sudo xattr -rd com.apple.quarantine /Applications/LaApp.app

defaults write

Personalización avanzada que no está en Settings

⚠️
Algunos cambios requieren reiniciar Dock/Finder. Podés revertir con defaults delete.
bash · defaults write 
━━━ DOCK ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Velocidad de animación del Dock (0 = instantáneo)
defaults write com.apple.dock autohide-delay -float 0
defaults write com.apple.dock autohide-time-modifier -float 0.3

# Reducir tamaño de iconos de carpetas en el Dock
defaults write com.apple.dock showhidden -bool true

# Deshabilitar "bounce" de iconos al abrir
defaults write com.apple.dock launchanim -bool false

killall Dock  # aplicar cambios del Dock

━━━ FINDER ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Mostrar archivos ocultos por defecto
defaults write com.apple.finder AppleShowAllFiles -bool true

# Mostrar extensiones de archivos siempre
defaults write NSGlobalDomain AppleShowAllExtensions -bool true

# Vista de lista por defecto en Finder
defaults write com.apple.finder FXPreferredViewStyle -string "Nlsv"

# Mostrar ruta completa en el título del Finder
defaults write com.apple.finder _FXShowPosixPathInTitle -bool true

# Deshabilitar advertencia al cambiar extensión
defaults write com.apple.finder FXEnableExtensionChangeWarning -bool false

killall Finder  # aplicar cambios del Finder

━━━ SCREENSHOTS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Cambiar carpeta de destino de screenshots
defaults write com.apple.screencapture location ~/Desktop/Screenshots
mkdir -p ~/Desktop/Screenshots

# Desactivar sombra en capturas de ventana
defaults write com.apple.screencapture disable-shadow -bool true

━━━ TECLADO Y TRACKPAD ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Repetición de teclas más rápida (dev workflow)
defaults write NSGlobalDomain KeyRepeat -int 2
defaults write NSGlobalDomain InitialKeyRepeat -int 15

# Deshabilitar auto-corrección (molesta al codear)
defaults write NSGlobalDomain NSAutomaticSpellingCorrectionEnabled -bool false
defaults write NSGlobalDomain NSAutomaticQuoteSubstitutionEnabled -bool false
defaults write NSGlobalDomain NSAutomaticDashSubstitutionEnabled -bool false
